rangnompee Studio is a desktop tool used by the creator of the TikTok account @rangnompee. It helps the creator produce short, vertical, 2D animated explainer videos in Thai and publish them to their own TikTok account.

How it works

  1. Create. The tool prepares a script, narration and 2D animation for a topic the creator chooses, and renders a 1080×1920 MP4 video.
  2. Review. Every video waits in a review screen. The creator watches it, checks the caption, and chooses the privacy level and whether comments, duets and stitches are allowed.
  3. Post. Only after the creator clicks Post does the tool upload the video to the creator's own TikTok account through the TikTok Content Posting API. Each video is labeled as AI-generated content.

TikTok integration

The tool uses TikTok Login Kit so the creator can sign in and authorize posting, and the Content Posting API to publish approved videos. It requests only the user.info.basic and video.publish scopes. It does not read other users' data.
